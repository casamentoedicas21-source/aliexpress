# AliExpress Sales AI

Plataforma de páginas de vendas de produto único, iniciada em React + Vite + TypeScript.

## Executar

```bash
npm install
npm run dev
```

## MVP

- Dashboard com cadastro de produtos e páginas
- Galeria de imagens, benefícios, FAQ, preço e temas
- Persistência local para demonstração
- Rotas de prévia em /p/slug
- Preparação de schema Supabase com RLS

**Atenção:** importação automática AliExpress, IA, checkout Mercado Pago e autenticação Supabase ainda não estão ativados. Não insira tokens em código ou formulários públicos.
